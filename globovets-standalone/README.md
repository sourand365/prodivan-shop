# Глобовец — автономная версия для Windows

Эта папка запускает прежние команды и отчёты бота вне NxCreate. Telegram-обработчики берутся из legacy.js, база NxCreate заменена локальной SQLite.

## Установка

1. Установи Node.js 20 LTS или новее.
2. Скопируй .env.example в файл .env.
3. Открой .env в Блокноте и укажи токен от @BotFather в строке BOT_TOKEN=...
4. В адресной строке Проводника введи cmd и нажми Enter.
5. Выполни по очереди:

    npm install
    npm run check
    npm start

Если в консоли появится «Глобовец запущен», отправь боту /start.

## Данные и резервные копии

- База: data/globovets.sqlite
- Резервные копии: data/backups (хранятся последние 7 копий).
- Для остановки нажми Ctrl+C в консоли.
- Не удаляй старый NxCreate-код и экспорт Telegram до проверки этой версии.

## Важно

- Бот работает, пока компьютер включён и подключён к интернету.
- Не запускай одновременно несколько копий с одним токеном.
- Перед постоянной эксплуатацией проверь ключевые команды в тестовом чате и группах.
- Прогноз погоды использует Open-Meteo и не требует API-ключа.
