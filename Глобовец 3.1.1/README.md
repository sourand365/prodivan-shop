# Глобовец 3.1.1

Папка для подготовки обновления версии 3.1.1.

Сюда загружаются исходные файлы текущей версии 3.1.0 для внесения исправлений:
- календарь: показывать записи Г, А, Б и Чай за каждый день; квесты исключить;
- «Топ месяц»: учитывать Чай при просмотре предыдущих месяцев.

Не загружайте сюда `.env`, токены бота или рабочую базу данных SQLite.
