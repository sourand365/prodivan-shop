# Глобовец 3.1.2 — автономная версия для Windows

Эта папка содержит автономную версию Telegram-бота «Глобовец». Telegram-обработчики находятся в `legacy.js`, локальная база SQLite создаётся в `data/globovets.sqlite`.

## Установка и запуск

1. Установи Node.js 20 LTS или новее.
2. Скопируй `.env.example` в файл `.env`.
3. Впиши токен от @BotFather в строку `BOT_TOKEN=...`.
4. Для обновления существующей установки запусти `START_UPDATE_312.bat` и следуй подсказкам. Скрипт создаёт резервную копию проекта, обновляет файлы 3.1.2, выполняет `npm install` и `npm run check`; `.env` и база `data/globovets.sqlite` не перезаписываются.
5. Для первой установки открой CMD в этой папке и выполни:

```powershell
npm install
npm run check
npm start
```

Если появится сообщение «Глобовец запущен», бот работает. Не запускай одновременно две копии с одним токеном.

## Что обновлено в 3.1.2

- Проверка достижений разделена по событиям: сразу после записи/действия, ежедневно в 23:59, по воскресеньям в 23:59 и в последний день месяца в 23:59.
- Условия и пороги заработка/чаевых приведены к согласованным правилам.
- «Первый выход» учитывает рабочие записи, включая «Чай» и «Этажи».
- Добавлено открытое достижение «Знакомство с чатом» за первое обычное текстовое сообщение в общем чате.
- У открытых достижений показывается дата получения. Для новых наград сохраняется дата по времени Киева.
- Добавлена отдельная система переходящих званий: «Папа на районе» обновляется по текущему лидеру месяца, «Лучший понедельник» и «Лучшая суббота» — по рекорду дня недели. При равном результате звание может принадлежать нескольким лидерам.
- «Абсолютный раб» теперь выдаётся за выполнение дневной цели 20 дней подряд.
- Администратор может просмотреть записи за дату командой `Логи (имя) (ДД.ММ.ГГГГ)`; прежняя команда `Запись` сохранена как псевдоним.
- Команда `Отмена (имя) номер` отменяет конкретную строку из последнего списка логов, в том числе за выбранную дату.
- После отмены обновляются суммы и выполняется повторная проверка достижений и званий.
- При обновлении не очищается существующая история достижений.

## Проверка

`npm run check` выполняет:

```powershell
node --check index.js
node --check legacy.js
```

GitHub Actions автоматически проверяет синтаксис файлов этой папки после изменений.

## Данные и резервные копии

- База: `data/globovets.sqlite`.
- Резервные копии: `data/backups` (последние 7 копий).
- Обновление кода не должно заменять `.env` или удалять папку `data`.
- Перед постоянной эксплуатацией проверь команды и достижения в тестовом чате.
