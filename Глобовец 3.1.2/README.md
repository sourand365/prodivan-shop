# Глобовец 3.1.2

Рабочая папка для подготовки обновления 3.1.2.

## План обновления

- Исправить общую систему выдачи достижений и повторно проверять условия по существующим записям.
- Исправить достижение «Первый выход»: учитывать любую рабочую запись, включая «Чай» и «Этажи».
- Добавить открытое достижение «Знакомство с чатом»: выдавать за первое обычное текстовое сообщение пользователя в общем чате.
- Показывать дату получения у каждого открытого достижения; сохранять фактическую дату и не придумывать неизвестные даты.
- Добавить админскую команду `Логи (имя) (дата)` для просмотра записей пользователя в хронологическом порядке с нумерацией.
- Добавить админскую команду `Отмена (имя) (номер)` для отмены выбранной записи из списка логов.
- После отмены корректно пересчитывать статистику и достижения.
- Сохранить совместимость с существующей SQLite-базой и `.env`; не сбрасывать пользовательские данные.
- Проверить `npm run check` и работу обновлятора.

Папка создана для подготовки обновления. Изменения в код бота пока не внесены.
