# Глобовец 3.2.1 — автономная версия для Windows

Это отдельная версия проекта. Старая папка и старая версия бота не изменяются.

## Установка с нуля

1. Установи Node.js 20 LTS или новее.
2. Скопируй `.env.example` в `.env`.
3. Открой `.env` и укажи токен от @BotFather в строке `BOT_TOKEN=...`.
4. В адресной строке Проводника открой `cmd` и выполни:

   ```bat
   npm install
   npm run check
   npm start
   ```

## Обновление существующей автономной версии

Сначала останови бота сочетанием Ctrl+C. Запусти `START_GLOBOVETS_321.bat` из папки проекта и следуй подсказкам. Обновлятор создаёт резервную копию файлов проекта, скачивает файлы именно версии 3.2.1, устанавливает зависимости и проверяет синтаксис.

## Что нового в 3.2.1

- Графическая карточка «Мой день» по выбранному макету №2: заработок за день, фактическое место в дневном топе, личная цель и зелёная полоса прогресса.
- В блоке «Записи за день» показываются только категории с ненулевыми фактическими суммами: Glovo, Bolt, Bolt TR, IPost, Ля, Чаевые; «Этажи» добавляются только если по ним есть запись. Пустые строки скрываются.
- Защита от повторной выдачи одноразовых достижений и от параллельного запуска проверки достижений в 23:59.
- Дата получения показывается у открытых достижений, если точная дата есть в сохранённых данных. Неизвестные даты не подставляются.
- Команда начисления квестов: `КВЕ 100` (старый формат `К 100` больше не используется).
- Квесты учитываются в недельной и месячной статистике, но не прибавляются к заработку конкретного дня и дневным целям.
- «Этажи» остаются в учёте без повторного добавления.
- Команды и ответы для жалоб отсутствуют.

## Данные и резервные копии

- SQLite: `data/globovets.sqlite`.
- Резервные копии: `data/backups` (последние 7 копий).
- Файл `.env`, база данных и папка с резервными копиями не заменяются обновлятором.
- Не запускай две копии бота с одним токеном одновременно.

Для остановки нажми Ctrl+C.
