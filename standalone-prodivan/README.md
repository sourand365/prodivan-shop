# Продаван — автономная версия для Windows

Эта папка — отдельный Node.js-проект. Она не использует файлы или базу «Глобовца» и не запускается внутри NxCreate.

## Установка

1. Откройте CMD и перейдите в эту папку после клонирования/скачивания репозитория.
2. Выполните `copy .env.example .env`.
3. Откройте `.env` в Блокноте и впишите токен отдельного бота «Продаван» после `BOT_TOKEN=`.
4. Выполните `npm install`.
5. Проверьте код: `npm run check`.
6. Запустите: `npm start`.

База создаётся локально в `data/prodivan.sqlite`. Не добавляйте файл `.env` или каталог `data` в GitHub.

## Реализовано в этой версии

- Главные разделы каталога: «Товары», «Аренда», «Комплектующие».
- Создание категорий внутри главных разделов.
- Создание товаров, изменение цены товара, приход и просмотр остатка.
- Оформление заказа с двумя полями: телефон и Telegram-юзернейм.
- Подтверждение заказа с вводом финальной суммы (скидка не меняет цену в карточке товара).
- Списание остатков только при подтверждении заказа.
- Две кассы: оплата зачисляется на кассу администратора, подтвердившего заказ.
- Просмотр касс, снятие с комментарием, перевод между кассами, история движений.
- Удаление пустых категорий. Категория с товарами не удаляется, чтобы не потерять каталог.

## Важно

Это новая локальная база: данные NxCreate автоматически не переносятся. Перед реальным использованием проверьте оформление, подтверждение и отмену тестового заказа. Это отдельная начальная автономная версия; не заменяйте ею старый бот в NxCreate.
