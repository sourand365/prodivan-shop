# MotoConnect — Android first

Первая тестовая платформа: Android. Клиент создаётся на Flutter, чтобы позднее добавить iOS без переписывания общей бизнес-логики.

## Статус
- Проектирование и подготовка структуры.
- Android — первая целевая платформа.
- iOS — следующий этап.
- Общие сервер и база данных с самого начала.

## План разработки
1. Основа Flutter-приложения и навигация Moto Sport.
2. Регистрация, вход и ожидание одобрения администратора.
3. Профиль и настройки темы.
4. Карта и безопасная передача геопозиции.
5. Голосовые каналы и личные звонки.
6. Группы и чаты.
7. Уведомления, фоновые режимы и тестирование на реальных Android-устройствах.

## Важно
Этот каталог содержит проектные документы. Само приложение ещё не собрано; APK будет подготовлен после реализации и проверки исходного кода.
